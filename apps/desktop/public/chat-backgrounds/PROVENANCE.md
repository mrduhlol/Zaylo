Videos are silent H.264, at most 640 × 360 bounding dimensions, 12 fps, preserving
source aspect ratio. The PNG is resized without altering its orientation; the
component rotates it 90 degrees with CSS. Canvas alpha keying removes dark or
light mattes and feathers edges at runtime. Portrait media is contained, never
stretched. No remote media is requested. Source-frame inspection found no page
chrome; this does not constitute a frame-by-frame certification of every clip.

The procedural ASCII cloud field in ChatBackground.tsx is original implementation
code. https://eooo.me/lab/ascii-clouds/ was a visual reference only. No minified
code or media from that site is included.
